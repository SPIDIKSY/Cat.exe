# CAT — шпаргалка для ИИ (одна страница)

CAT — статически типизированный низкоуровневый язык. Все слова кошачьи. Файл `.cat`, кодировка UTF-8.

## Рабочий цикл
```
python -m catlang fmt prog.cat            # привести к единому виду
python -m catlang check prog.cat --json   # ошибки в JSON: code, line, column, message, source
python -m catlang wasm prog.cat --html      # в WebAssembly + страница для браузера (пока без массивов/строк-значений/структур)
python -m catlang run prog.cat [--seed N] # запуск (код выхода: 0 ок, 1 ошибка компиляции, 3 ошибка выполнения)
```
Правь по `code` и `line`/`column`, перезапускай `check`, пока не будет `"ok": true`. Тесты: `python -m unittest discover -t . -s tests`.

## Слова
| Слово | Смысл | | Слово | Смысл |
|---|---|---|---|---|
| `purr` | функция | | `bring` | return |
| `yarn` | переменная | | `like` | приведение типа (`x like u8`) |
| `sniff` / `hiss` | if / else | | `yes` / `no` | true / false |
| `chase` | while | | `kit` | структура |
| `prowl i among a..b` | for, `i` от `a` до `b-1` | | `ghost` | пустая ссылка |
| `scat` / `hop` | break / continue | | `adopt` | подключить модуль |
| **`C` `A` `T` `S`** | **И, ИЛИ, НЕ, искл. ИЛИ** (только заглавные!) | | `&&` `||` | и/или для `bool`, короткое вычисление |

Приоритет от слабого к сильному: `||` `&&` `A` `S` `C` `== !=` `< <= > >=` `<< >>` `+ -` `* / %` `like` унарные `T` `-`.
Комментарий: `// ...`. Операторов `!`, `++`, `+=`, `?:` нет. Условие `sniff`/`chase` — без скобок, тело — всегда в `{}`.

## Типы
`bool u8 u16 u32 u64 i8 i16 i32 i64 str [T]` и структуры. **Неявных преобразований нет**: `u8 + u16` — ошибка, пиши `a like u16`.
Целый литерал берёт тип из контекста (`yarn x: u8 = 5;`), без контекста он `i64`. Целые оборачиваются по модулю (255u8 + 1 = 0).
Индекс массива/строки — только `u32`. `T` и `C A S` работают и на целых (побитово), и на `bool`.

## Встроенные функции
`meow(x)` печать со строкой · `mew(x)` печать без переноса (`x`: число, `bool`, `str`) · `claw(cond)` проверка ·
`ask()` → i64 (число с клавиатуры) · `heard()` → bool (прошлое `ask` было числом) · `listen()` → str ·
`roll(n: u32)` → u32 случайное 0..n-1 · `stretch(x)` → u32 длина массива/строки · `scribble(n)` число → str ·
`bury(x)` освободить память · `look8/16/32/64(addr)` / `bat8/16/32/64(addr, v)` сырая память (адреса 0..65535).
Модуль: `adopt math;` → `math.gcd(a, b)`, `math.abs`, `math.min`, `math.max`, `math.pow`, `math.isqrt`.

## Образцы
```
purr fib(n: u32) -> u32 {
    sniff n < 2 { bring n; }
    bring fib(n - 1) + fib(n - 2);
}

kit Node { value: u32, next: Node }            // структура (ссылка на объект в куче)

purr main() {
    yarn total: u32 = 0;
    prowl i among 0..10 { total = total + fib(i like u32); }   // i: i64 -> привести
    meow("сумма: " + scribble(total));                          // строки: + и ==
    yarn a: [u8] = [0; 4];                                      // массив из 4 нулей
    a[1] = 200;
    yarn head: Node = ghost;
    head = Node(1, head);                                       // создание структуры
    sniff head.next == ghost && a[1] > 100 { meow("ok"); }
    mew("число: "); yarn n = ask();
    sniff T heard() { meow("не число"); }
}
```

## Частые ловушки
* `S`, `C`, `A`, `T` — зарезервированные имена (нельзя назвать так переменную или структуру).
* `print`, `fn`, `let`, `if`, `while`, `true` ничего не значат — используй слова из таблицы.
* В `prowl i among 0..n` тип `i` — тип границ (`n: u32` → `i: u32`; два литерала → `i64`).
* Строки неизменяемы (UTF-8 байты, `stretch` считает байты). Массивы и структуры — ссылки: `b = a` не копирует.
* Память не освобождается сама — `bury(x)`; использование после `bury` — ошибка выполнения (`invalid reference`).
* Функция с типом результата обязана вернуть значение на всех путях.
* `main` — без параметров, возвращает ничего или `i32` (код выхода).
