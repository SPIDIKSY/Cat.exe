# Байткод CAT и формат `.catc` (версия 1)

Все числа little-endian.

## Файл

```
"CATB"            4  магия
version  u16         = 1
flags    u16         бит0 = есть секция отладки
entry    u32         индекс функции main
nsec     u16         число секций
секции:  [id u8][длина u32][данные]
crc32    u32         CRC32 всего предыдущего содержимого файла
```

| id | Секция | Содержимое |
|---|---|---|
| 1 | CONST | `u16 n`, затем `n × (u32 длина, UTF-8)` — строки |
| 2 | FUNC  | `u16 n`, затем `n × (u32 entry, u16 nargs, u16 nlocals)` |
| 3 | CODE  | инструкции |
| 4 | DEBUG | `u16+имя файла`, `u16 n + имена функций`, `u32 n + n×(u32 pc, u32 строка)`; удаляется `--strip` |

Загрузчик отклоняет файл при неверной магии, версии, CRC, обрезанных/повторных секциях
и при любом нарушении верификатора (см. `vm/format.py: verify`).

## Типы (1 байт)

`0 bool · 1 u8 · 2 u16 · 3 u32 · 4 u64 · 5 i8 · 6 i16 · 7 i32 · 8 i64`

## Инструкции

Стек справа. `T` — операнд-тип. Операнды берутся канонически (знаковые — отрицательными).

| Код | Имя | Операнд | Действие |
|---|---|---|---|
| 00 | HALT | | остановка, код выхода 0 |
| 01 | PUSH | T + u64 | положить константу |
| 02 | POP / 03 DUP | | убрать / дублировать верх |
| 10 | LOAD | u16 слот | положить локальную |
| 11 | STORE | u16 слот | снять в локальную |
| 20 | CAT | T | `a b → a AND b` |
| 21 | CATS | T | `a b → a OR b` |
| 22 | PAW | T | `a b → a XOR b` |
| 23 | MEOW | T | `a → NOT a` (в ширине T) |
| 30–34 | ADD SUB MUL DIV REM | T | арифметика; DIV/REM на 0 — ловушка |
| 35 | NEG | T | `a → -a` |
| 36 / 37 | SHL / SHR | T | сдвиг; SHR знаковых — арифметический; сдвиг ≥ ширины — ловушка |
| 40–45 | EQ NE LT LE GT GE | T = тип операндов | `a b → bool` |
| 50 | CAST | T = целевой | привести к T (усечение/расширение по знаку) |
| 60 / 61 / 62 | JMP / JZ / JNZ | u32 адрес | переход (JZ/JNZ снимают условие) |
| 70 | CALL | u16 функция | вызов |
| 71 / 72 | RET / RETV | | возврат со значением / без |
| 80 / 81 / 82 | PRINTI / PRINTB / PRINTS | / / u16 строка | печать со снятием значения + `\n` |
| 83 / 84 / 85 | WRITEI / WRITEB / WRITES | / / u16 строка | то же, что PRINT*, но без `\n` |
| 86 | READI | | читает строку, кладёт `i64`; не число → 0 и `INOK`=false; конец ввода — ловушка |
| 87 | INOK | | кладёт `bool`: последний READI был числом |
| 88 | RAND | | `n → число в 0..n-1` (xorshift64: сдвиги и PAW; зерно — ключ `--seed`) |
| 90 / 91 | LOADM / STOREM | T | `addr → v` / `addr v →` |
| B0 / B1 | ALOAD / ASTORE | T = тип элемента | `h i → v` / `h i v →`; индекс проверяется; ссылки хранятся как u32 |
| B2 / B3 | ALEN / NEWARR | / T | `h → длина` / `v n → h` (массив из n копий v) |
| B4 | STR | u16 | положить адрес строки-константы |
| B5 / B6 / B7 | SCAT / STREQ / ITOS | | сцепить / сравнить / число → строка |
| B8 / B9 / BA | READS / PRINTV / WRITEV | | прочитать строку / напечатать строку (с `\n` / без) |
| BB | NEWS | u16 размер | создать структуру (нули), положить ссылку |
| BC / BD | FLOAD / FSTORE | T + u16 смещение | `h → v` / `h v →` |
| BE | FREE | | `h →` освободить объект |
| A0 | ASSERT | | снять `bool`, если ложь — ловушка |

## Память

4 МиБ. `0..65535` — «пользовательская» область для `look*/bat*` (peek/poke). Выше — куча.

**Объект** = заголовок 8 байт `[u32 длина или размер][u32 вид]` + данные, выровнен по 8. Вид: 1 массив, 2 строка, 3 структура.
**Ссылка** (u32) = `(поколение << 19) | (адрес >> 3)`. Ноль — пустая ссылка (`ghost`).
**Выделение:** сначала список свободных блоков того же размера, иначе новый участок; при нехватке — ловушка `out of memory`.
**Освобождение** (`bury`): блок возвращается в список. При повторном использовании его поколение растёт, поэтому
старые ссылки на него недействительны («use-after-free» и двойное освобождение ловятся, а не портят данные).
**Проверки на каждом обращении:** ссылка жива и поколение совпадает; вид объекта подходит операции (поле — только у
структуры, запись по индексу — только у массива, строки неизменяемы); индекс/смещение в границах; константы-строки
освободить нельзя. Подделать ссылку числом нельзя.
Ограничения: блоки одного размера переиспользуются точно (без слияния соседних — возможна фрагментация);
поколений 8191, после этого счётчик идёт по кругу.

Логические инструкции CAT/CATS/PAW/MEOW исполняются через АЛУ: быстрое (`FastALU`) или
гейтовое (`GateALU`, ключ `--gates`).
