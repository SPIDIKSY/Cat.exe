# Грамматика CAT (EBNF)

Комментарии: `// до конца строки`. Пробелы и переводы строк не значимы.

```ebnf
program   = { use | struct | func } ;
struct    = "kit" ident "{" [ ident ":" type { "," ident ":" type } [ "," ] ] "}" ;
use       = "adopt" ident ";" ;
func      = "purr" ident "(" [ param { "," param } ] ")" [ "->" type ] block ;
param     = ident ":" type ;
type      = "[" type "]" | "str" | "bool" | "u8" | "u16" | "u32" | "u64" | "i8" | "i16" | "i32" | "i64" ;

block     = "{" { stmt } "}" ;
stmt      = "yarn" ident [ ":" type ] "=" expr ";"
          | ident "=" expr ";"
          | postfix "[" expr "]" "=" expr ";"   (* запись в элемент массива *)
          | postfix "." ident "=" expr ";"      (* запись в поле структуры *)
          | "sniff" expr block [ "hiss" ( if_stmt | block ) ]
          | "chase" expr block
          | "prowl" ident "among" expr ".." expr block   (* i = начало .. конец-1 *)
          | "scat" ";" | "hop" ";"
          | "bring" [ expr ] ";"
          | block
          | expr ";" ;

expr      = lor ;                       (* уровни от слабого к сильному *)
lor       = land  { "||" land } ;       (* только bool, короткое вычисление *)
land      = or    { "&&" or } ;
or        = xor   { "A" xor } ;
xor       = and   { "S"  and } ;
and       = equal { "C"  equal } ;
equal     = order { ("==" | "!=") order } ;
order     = shift { ("<" | "<=" | ">" | ">=") shift } ;
shift     = sum   { ("<<" | ">>") sum } ;
sum       = term  { ("+" | "-") term } ;
term      = cast  { ("*" | "/" | "%") cast } ;
cast      = unary { "like" type } ;
unary     = "T" unary | "-" unary | postfix ;
postfix   = primary { "[" expr "]" | "." ident } ;   (* индекс (u32) или поле структуры *)
primary   = int | string | "[" expr { "," expr } "]"       (* литерал массива *)
          | "[" expr ";" expr "]"                       (* [значение; сколько] *)
          | int | string | "yes" | "no" | "(" expr ")"
          | "ghost"                                             (* пустая ссылка *)
          | ident [ "." ident ] "(" [ expr { "," expr } ] ")"   (* вызов; Имя(значения) — создание структуры *)
          | ident ;

int       = dec | "0x" hex | "0b" bin ;  (* допускается "_": 1_000_000 *)
string    = '"' { char | "\n" | "\t" | "\\" | "\"" | "\0" } '"' ;
ident     = (letter | "_") { letter | digit | "_" } ;
```

## Слова языка (всё кошачье)

| Слово | Значит | | Слово | Значит |
|---|---|---|---|---|
| `purr` | `fn` — функция | | `yes` / `no` | `true` / `false` |
| `yarn` | `let` — переменная | | `adopt` | `use` — подключить модуль |
| `sniff` / `hiss` | `if` / `else` | | **`C`** | **И** (AND) |
| `chase` | `while` | | **`A`** | **ИЛИ** (OR) |
| `prowl … among` | `for … in` | | **`T`** | **НЕ** (NOT) |
| `scat` / `hop` | `break` / `continue` | | **`S`** | **исключающее ИЛИ** (XOR) |
| `bring` | `return` | | `like` | `as` — приведение типа |
| `kit` | `struct` — структура | | `ghost` | пустая ссылка (null) |

Сердце языка — четыре **заглавные** буквы `C A T S` (одна буква — один оператор; поэтому имена `C`, `A`, `T`, `S`
заняты). Типы: `bool u8 u16 u32 u64 i8 i16 i32 i64`.

Массивы и строки живут в куче: `yarn a: [u8] = [0; 10];`, `a[3] = 7;`, `yarn s = "кот" + "!";`.
Массив — ссылка (передача в функцию не копирует). Строки неизменяемы, хранятся как UTF-8 байты:
`stretch(s)` — длина в байтах, `s[i]` — байт. Память пока не освобождается (см. DESIGN).

Структуры: `kit Point { x: i32, y: i32 }`, создание `Point(1, 2)`, доступ `p.x`, запись `p.x = 5;`.
Как и массивы, структура — ссылка на объект в куче. Поля выровнены по своему размеру, размер объекта кратен 8
(`kit { a: u8, b: u32, c: u8 }` → смещения 0, 4, 8, размер 16). Поле может быть любого типа, в том числе
структурой, массивом, строкой. `ghost` — пустая ссылка: подходит к любому ссылочному типу
(`yarn n: Node = ghost;`, `sniff n != ghost`); обращение к ней — ошибка выполнения.
`==`/`!=` для массивов и структур сравнивают «тот же ли это объект» (для строк — содержимое).
Имена `S`, `C`, `A`, `T` заняты (операторы), структуру так назвать нельзя.
`bury(x)` освобождает массив/строку/структуру; после этого ссылка недействительна (ошибка при использовании).

Встроенные функции: `bury(x)` освободить память · `stretch(x)` длина массива/строки · `scribble(n)` число → строка · `listen()` ввод строки · `meow(x)` печать со строкой · `mew(x)` печать без переноса · `claw(cond)` проверка ·
`ask()` ввод числа · `heard()` «число введено?» · `roll(n)` случайное 0..n-1 ·
`look8/16/32/64(addr)` чтение памяти · `bat8/16/32/64(addr, v)` запись в память.
Прежние английские слова (`fn`, `print`, `cat` …) ничего не значат — это обычные имена.
Все слова задаёт один файл: `catlang/compiler/vocab.py`.

Правила типов: оба операнда бинарной операции одного типа; условия — `bool`;
`<` `<=` `>` `>=` — только для целых; `-` (унарный) — только для знаковых;
строки — только аргумент `print`; `main` — без параметров, возвращает ничего или `i32`.
